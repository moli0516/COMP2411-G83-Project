# Fictional seed coverage checklist

- [ ] Customers/equipment with meaningful relationships
- [ ] Multi-item request and undelivered item
- [ ] Quote revisions and accepted quotation
- [ ] Equipment with one versus repeated received repair
- [ ] First-round PASS and FAIL; later successful reinspection
- [ ] Legitimate null completion, return and verification fields
- [ ] OPEN/IN_PROGRESS/RESOLVED/VERIFIED actions
- [ ] Shared action linked to incidents across jobs
- [ ] Staff with zero matching jobs/actions
- [ ] HAVING groups retained and rejected
- [ ] Subquery matching/non-matching cases
- [ ] Fixed dates and known expected row sets

Use deterministic fictional IDs. Agree fixture ownership. Counts alone are not coverage.
